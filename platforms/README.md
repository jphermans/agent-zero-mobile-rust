# platforms/

Native iOS + Android frontends over the shared Rust core (`a0-platform` crate,
UniFFI 0.31 bindings). Architecture: `docs/phase1/architecture.md` (sections
1.7, 6); feature mapping: `docs/phase1/feature-parity.md` (section 4).

## Layout

| Path | What | Status |
|---|---|---|
| `ios/project.yml` | XcodeGen spec for the AgentZero app | checked in |
| `ios/AgentZero.xcodeproj/project.pbxproj` | Hand-authored minimal Xcode project (objectVersion 56) | checked in — regenerable |
| `ios/Sources/` | SwiftUI app sources (13 .swift files) | checked in |
| `ios/RustBridge/` | Local SPM package exposing A0Platform | Package.swift checked in; Sources/Frameworks generated |
| `ios/Generated/` | Intermediates from `scripts/build-ios.sh` | generated |
| `android/` | Gradle project (app + A0Rust modules) | checked in (see per-module notes) |
| `android/gradle/wrapper/gradle-wrapper.properties` | Wrapper config (Gradle 8.10.2) | checked in |
| `android/gradle/wrapper/gradle-wrapper.jar` | Wrapper JAR | **generated — see gaps** |
| `android/A0Rust/src/main/jniLibs/` | `liba0_platform.so` per ABI | generated by `scripts/build-android.sh` |
| `android/A0Rust/src/main/kotlin/` | UniFFI Kotlin bindings (`um.a0.platform`) | generated by `scripts/build-android.sh` |

## Local verification — Android

Prerequisites: JDK 17, Android SDK (API 35) + NDK r28+, `ANDROID_NDK_HOME`
set, rustup stable + targets `aarch64-linux-android`, `armv7-linux-androideabi`,
`x86_64-linux-android`, `cargo-ndk`, the in-workspace bindgen (see
`scripts/bootstrap.sh`).

```bash
./scripts/build-android.sh
cd platforms/android
gradle wrapper --gradle-version 8.10.2   # one-time: materializes gradle-wrapper.jar
./gradlew assembleDebug
```

Expected artifacts: `app/build/outputs/apk/debug/app-debug.apk`; jniLibs +
Kotlin bindings under `A0Rust/src/main/` (see table above).

## Local verification — iOS

Prerequisites: macOS, Xcode 16+, rustup stable + targets `aarch64-apple-ios`,
`aarch64-apple-ios-sim`, `x86_64-apple-ios`, the in-workspace bindgen,
XcodeGen (`brew install xcodegen`) for regeneration.

```bash
./scripts/build-ios.sh
# Optional but recommended if the hand-authored pbxproj ever drifts:
cd platforms/ios && xcodegen generate
cd ..
xcodebuild build -project ios/AgentZero.xcodeproj -scheme AgentZero \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO
```

Expected artifacts: `ios/RustBridge/Frameworks/A0Platform.xcframework`,
`ios/RustBridge/Sources/A0Platform/A0Platform.swift`, app binary from
xcodebuild.

## Known gaps

1. **Gradle wrapper JAR**: only `gradle-wrapper.properties` is checked in;
   run `gradle wrapper` once (see above) to materialize `gradle-wrapper.jar`
   and `gradlew`.
2. **Xcode project regeneration**: `project.pbxproj` is hand-authored
   (validated structure; UUID-unique, fully back-referenced). If anything
   drifts, `xcodegen generate` regenerates a canonical project from
   `project.yml` — the XcodeGen output wins.
3. **Signing**: no team IDs/provisioning profiles configured (iOS
   `DEVELOPMENT_TEAM` empty; Android release build unsigned). Configure real
   signing before App Store / Play distribution.
4. **Generated bindings API names**: Swift/Kotlin sources call the generated
   UniFFI facade through thin wrappers (`Services/RustBridge.swift`,
   `rust/RustBridge.kt`) with `TODO(bindings)` markers where generated type
   names are finalized at binding-generation time.
